Validation Cloud gives AI agents and automation the same access to Mavrik and your team's Node API account that you have in the dashboard. Your agent works with the account, plan and roles your team already has: it can manage endpoints, check usage and compute-unit costs, send RPC calls through your endpoints, and ask Mavrik about digital-asset markets.

## Choose how to connect

Pick the one that fits where your agent runs. The MCP server and the CLI share one login and one set of permissions. The skill uses an Admin API key.

## Connect, prompt, execute

Three steps, whichever client you use.

<Steps>
  <Step title="Connect">
    Add the MCP server to your client, or install the CLI, then log in with your Validation Cloud account. For Claude Code:

    ```bash
    claude mcp add --transport http validation-cloud https://mcp.validationcloud.io/mcp
    ```

    See [MCP server](/agents/mcp#connect-your-client) for Codex, Cursor, VS Code and other clients.
  </Step>
  <Step title="Prompt">
    Describe what you need in plain language. The agent picks the tool and its parameters, within your plan and your role.

    > "Create a Base mainnet endpoint for staging and give me the HTTPS URL."

    Tools it calls: `nodeapi.create_endpoint`, `nodeapi.get_endpoint`.
  </Step>
  <Step title="Execute">
    The agent runs the tools against your team's account and brings the results back into the conversation.

    > "Show this month's compute-unit usage, by day."

    Tool it calls: `nodeapi.get_team_usage`.
  </Step>
</Steps>

## Tools

The MCP server exposes twelve tools, grouped by product:

- **Node API (11):** your account and plan, supported chains, compute-unit costs, endpoints, team and endpoint usage, and RPC calls through your endpoints.
- **Mavrik (1):** ask a question about digital-asset markets, wallets or flows in plain language.

See the [full list of tools](/agents/mcp#tools), with their parameters.

## FAQ

<AccordionGroup>
  <Accordion title="What should I use?">
    The MCP server when your agent lives in an editor or a chat client and you want tool calls with no setup beyond a login. The CLI when the work happens in a shell, a script or CI. The skill when you want Claude Code or Codex to write code against the Admin API.
  </Accordion>
  <Accordion title="Do I need a key?">
    No. The MCP server and the CLI log in with your Validation Cloud account in the browser and inherit your team's plan and your role, so there is no key to create. The Admin API skill is the exception: it uses an [Admin API key](/nodeapi/about/admin-api-keys) from your dashboard.
  </Accordion>
  <Accordion title="What does it cost?">
    Every tool works on every plan except creating and deleting endpoints, which need the Scale plan. Deleting an endpoint also needs the Admin role on the team. RPC calls made through an agent are metered in compute units, like any other request to the same endpoint. See [Plans and billing](/nodeapi/about/billing).
  </Accordion>
</AccordionGroup>
