title: "Agents"
description: "Connect AI agents, scripts and CI jobs to Mavrik and your Node API account."
---

Validation Cloud gives AI agents and automation the same access to Mavrik and your team's Node API account that you have in the dashboard.

* [MCP Server](/agents/mcp): connect Claude Code, Codex, Cursor, VS Code or any MCP client
* [CLI](/agents/cli): call the same tools from your terminal, shell scripts and CI jobs
