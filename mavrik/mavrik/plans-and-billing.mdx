**Mavrik has three plans.**&#x20;

Billing is primarily based on monthly prompt volume. Your plan also determines whether you can create Custom Monitors, access Recon, and receive enterprise support.

### Mavrik Plans

|                | Free         | Pro               | Enterprise        |
| -------------- | ------------ | ----------------- | ----------------- |
| Cost (monthly) | $0           | $20               | Custom            |
| Prompts        | 10 per month | 50 per month      | Unlimited         |
| MCP Connectors | -            | -                 | Included          |
| Mavrik Chat    | Included     | Included          | Included          |
| Mavrik Monitor | Featured     | Featured & Custom | Featured & Custom |
| Mavrik Recon   | -            | -                 | Included          |
| Support        | Standard     | Priority          | Dedicated Channel |
