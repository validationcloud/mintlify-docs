## Node API vs. Private Chains

We run RPC nodes for 80+ blockchains. Some are available directly in the Node API product today; others are Private Chains, provisioned for your account if you are on a [Private Plan](/nodeapi/about/billing#private-plan) or [contact us](https://www.validationcloud.io/contact).

If you would like to know more about our private chain support or discuss specific integration requirements, you can talk to us using the link above.

We are continuously expanding our infrastructure to meet the evolving needs of the Web3 ecosystem.

## Supported Chains and Archive Coverage

The following chains and networks are supported by Validation Cloud. This combines Node API and Private Chains into one reference, showing availability, archive status, and history retention for each.

To find a specific chain or network, use your browser's find (Ctrl+F or ⌘F). Scroll the table sideways to see every column.

* **Archive State**: how far back state queries work at historical blocks (`eth_getBalance`, `eth_call`, `eth_getStorageAt` with a block parameter). "Recent only" means the standard full-node window, roughly the last 128 blocks. For non-EVM chains, where point-in-time state queries do not exist in the protocol, this shows whether the complete chain history is queryable.
* **Block & Log History**: how far back you can read blocks, transactions, receipts and `eth_getLogs`. "Full" means back to the first block of the chain.
