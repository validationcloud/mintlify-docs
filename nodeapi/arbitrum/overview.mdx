Arbitrum One is a Layer-2 scaling solution for Ethereum that uses optimistic rollups to enable faster and cheaper transactions while inheriting Ethereum’s security.&#x20;

Fully compatible with the Ethereum Virtual Machine (EVM), Arbitrum One allows developers to deploy existing Ethereum dApps with minimal changes and benefit from greater scalability.

Block explorer: [https://arbiscan.io/](https://arbiscan.io/)
