---
title: "trace_rawTransaction"
---

Traces a signed transaction that has not yet been included in a block, without broadcasting it.

This method will use `80` [Compute Units](/nodeapi/about/billing).

> The transaction must be signed by an account whose nonce has not yet been used. Passing an already-mined transaction returns `nonce too low`.

***

## **Parameters**

`data` - String - <span style={{color: "red"}}>Required</span> - The signed transaction data, as a hexadecimal string

`array` - Array - <span style={{color: "red"}}>Required</span> - The type of trace, which can be one of the following:

* `trace` - string - To get the basic trace of the given transaction
* `stateDiff` - string - To get information on altered state due to execution of the given transaction
* `vmTrace` - string - To get a full trace of the virtual machine's state during the execution of the given transaction, including for any subcalls

## **Returns**

`object` - object - The transaction trace result object

* `output` - string - The data returned as output encoded in hexadecimal format
* `stateDiff` - object - The altered state due to execution of the given transaction, or null if not requested
* `trace` - array - An array of basic trace objects for the given transaction containing:
  * `action` - object - The ParityTrace action object containing call details
    * `from` - string - The address of the sender
    * `callType` - string - The type of method such as call, staticcall, delegatecall
    * `gas` - string - The gas provided by the sender, encoded as hexadecimal
    * `input` - string - The input data sent along with the transaction
    * `to` - string - The address of the receiver
    * `value` - string - The integer of the value sent with this transaction, encoded as hexadecimal
  * `result` - object - The execution result of the trace
    * `gasUsed` - string - The amount of gas used by this trace
    * `output` - string - The return value of the contract call, empty if no RETURN executed
  * `subtraces` - integer - The number of subtraces (internal calls) within this trace
  * `traceAddress` - array - The list of addresses where the call executed, including parent calls and order
  * `type` - string - The type of the trace, such as call or create
* `vmTrace` - object - The full trace of the virtual machine's state during execution, or null if not requested
