---
title: "platform.getHeight"
---

Returns the height of the last accepted block.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://docs.avax.network/reference/avalanchego/p-chain/api#platformgetheight)

## **Parameters**

`None`&#x20;

## Returns

`height` - int

```json
// Result
{
  "jsonrpc": "2.0",
  "result": {
    "height": "56"
  },
  "id": 1
}
```
