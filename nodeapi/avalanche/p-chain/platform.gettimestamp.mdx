---
title: "platform.getTimestamp"
---

Get the current P-Chain timestamp.

This method will use `90` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://build.avax.network/docs/rpcs/p-chain/chain-info/platform_getTimestamp)

## **Parameters**

`None`

## Returns

* `timestamp` - string - The timestamp of the current P-chain.

```json
// Results
{
  "jsonrpc": "2.0",
  "result": {
    "timestamp": "2021-09-07T00:00:00-04:00"
  },
  "id": 1
}
```
