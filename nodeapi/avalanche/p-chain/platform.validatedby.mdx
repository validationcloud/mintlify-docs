---
title: "platform.validatedBy"
---

Get the Subnet that validates a given blockchain.

This method will use `80` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://build.avax.network/docs/rpcs/p-chain/blockchains/platform_validatedBy)

## **Parameters**

* `blockchainID` - string - the blockchain’s ID.

## Returns

* `subnetID` - string - the ID of the Subnet that validates the blockchain.

```json
// Result
{
  "jsonrpc": "2.0",
  "result": {
    "subnetID": "2bRCr6B4MiEfSjidDwxDpdCyviwnfUVqB2HGwhm947w9YYqb7r"
  },
  "id": 1
}
```
