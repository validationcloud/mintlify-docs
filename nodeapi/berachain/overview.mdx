Berachain is a high-performance EVM-Identical Layer 1 (L1) blockchain utilizing Proof-of-Liquidity (PoL) as a consensus mechanism.

Block explorer:

* Mainnet: [https://beratrail.io/](https://beratrail.io/)
* Testnet (bepolia): [https://bepolia.beratrail.io/](https://bepolia.beratrail.io/)

\
[Learn more by visiting Berachain's developer docs](https://docs.berachain.com/).

## Network Support
| Network | Full History / Archive | HTTPS | WSS |
| --- | --- | --- | --- |
| Mainnet | ✅ | ✅ | ✅ |

> WebSocket clients **MUST** respond to server `ping` frames, otherwise the connection will be closed and re-established every minute.

## Getting Started

Send a request to check that your endpoint works. Replace `<YOUR_API_KEY_HERE>` with the key from your endpoint in the [Validation Cloud app](https://app.validationcloud.io/node).

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.berachain.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":0}'
```

```bash title="testnet"
curl https://bepolia.berachain.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":0}'
```

</CodeGroup>

Connect over WebSocket:

<CodeGroup>

```bash title="mainnet"
wscat -c wss://mainnet.berachain.validationcloud.io/v1/wss/<YOUR_API_KEY_HERE>
```

```bash title="testnet"
wscat -c wss://bepolia.berachain.validationcloud.io/v1/wss/<YOUR_API_KEY_HERE>
```

</CodeGroup>
