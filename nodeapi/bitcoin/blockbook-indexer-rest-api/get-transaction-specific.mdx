---
title: "Get transaction specific"
---

Returns transaction data in the exact format as returned by backend, including all coin specific fields.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## **Reference:** [**Here**](https://github.com/trezor/blockbook/blob/master/docs/api.md#get-transaction-specific)

```bash
GET /api/v2/tx-specific/<txid>
```

## **Parameters**

**`transaction id (hash)`**- string, required.

Example: `0694bfc6ff68e55975718e9547c5343db4afcdfa783cc8421ddd50642677892b`
