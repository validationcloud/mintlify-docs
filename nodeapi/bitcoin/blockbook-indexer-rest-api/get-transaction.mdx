---
title: "Get transaction"
---

Get transaction returns "normalized" data about a transaction.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## **Reference:** [**Here**](https://github.com/trezor/blockbook/blob/master/docs/api.md#get-transaction)

```bash
GET /api/v2/tx/<txid>
```

## **Parameters**

**`transaction id (hash)`**- string, required.

Example: `0694bfc6ff68e55975718e9547c5343db4afcdfa783cc8421ddd50642677892b`
