---
title: "GET /block/:hash"
---

Returns information about a block.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

**`block`**- block hash, required.

Example: `0000000000000000000226ab487ff1a8456a30feb1bde3d65b6a67128074e19a`

## Returns

Returns information about the transaction.

Available fields: `txid`, `version`, `locktime`, `size`, `weight`, `fee`, `vin`, `vout` and `status` (see [transaction format](https://github.com/Blockstream/esplora/blob/master/API.md#transaction-format) for details).

The response from this endpoint can be cached indefinitely.
