---
title: "GET /blocks[/:start_height]"
---

Returns the 10 newest blocks starting at the tip or at `start_height` if specified.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

`start_height` -  optional.&#x20;

Example: `910883`

## Returns

Returns the 10 newest blocks starting at the tip or at `start_height` if specified.
