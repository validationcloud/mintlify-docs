---
title: "GET /tx/:txid/merkle-proof"
---

Returns a merkle inclusion proof for the transaction using [Electrum's `blockchain.transaction.get_merkle`](https://electrumx.readthedocs.io/en/latest/protocol-methods.html#blockchain-transaction-get-merkle) format.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

**`txid`**- transaction hash, required.

Example: `92e61d56a3d79fd6b2fc53d4577f51faa61485e0165eae746a6f3ded5b994655`

## Returns

Returns a merkle inclusion proof for the transaction using [Electrum's `blockchain.transaction.get_merkle`](https://electrumx.readthedocs.io/en/latest/protocol-methods.html#blockchain-transaction-get-merkle) format.
