---
title: "GET /tx/:txid/status"
---

Returns the transaction confirmation status.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

**`txid`**- transaction hash, required.

Example: `92e61d56a3d79fd6b2fc53d4577f51faa61485e0165eae746a6f3ded5b994655`

## Returns

Returns the transaction confirmation status.

Available fields: `confirmed` (boolean), `block_height` (optional) and `block_hash` (optional).

```json
{
	"confirmed": true,
	"block_height": 910150,
	"block_hash": "0000000000000000000226ab487ff1a8456a30feb1bde3d65b6a67128074e19a",
	"block_time": 1755254187
}
```
