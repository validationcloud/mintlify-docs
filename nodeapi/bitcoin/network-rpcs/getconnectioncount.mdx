---
title: "getconnectioncount"
---

Returns the number of connections to other nodes.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## **Reference:** [**Here**](https://developer.bitcoin.org/reference/rpc/getconnectioncount.html)

## Returns

| Name | Type    | Description          |
| ---- | ------- | -------------------- |
| n    | numeric | The connection count |

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.bitcoin.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
 -X POST \
 -H "Content-Type: application/json" \
 -d '{
	"jsonrpc": "1.0",
	"id": "curltest",
	"method": "getconnectioncount",
	"params": []
}'
```
