---
title: "eth_getUncleByBlockNumberAndIndex"
---

Returns information about a uncle of a block by number and uncle index position.

This method will use `20` [Compute Units](/nodeapi/about/billing).

**Note**: There is no concept of uncle (aka ommer) blocks in Conflux. The `eth_getUncleByBlockHashAndInde`x and `eth_getUncleByBlockNumberAndIndex` methods will always return null.

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth_getunclebyblocknumberandindex)

## **Parameters**

1. `QUANTITY|TAG` - a block number, or the string `"earliest"`, `"latest"` or `"pending"`, as in the [default block parameter](https://ethereum.org/en/developers/docs/apis/json-rpc/#default-block-parameter).
2. `QUANTITY` - the uncle's index position.

```json
params: [
  "0x29c", // 668
  "0x0", // 0
]
```
