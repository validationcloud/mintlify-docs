title: "JSON RPC Relay API"
---

A specification of the Ethereum JSON RPC APIs interface for Hedera clients.

## Websocket Methods

The Hedera JSON-RPC Relay websocket server only handles the following methods:

* [eth\_subscribe](/nodeapi/hedera/json-rpc-relay-api/eth_subscribe)
* [eth\_unsubscribe](/nodeapi/hedera/json-rpc-relay-api/eth_unsubscribe)
* [eth\_chainId](/nodeapi/hedera/json-rpc-relay-api/eth_chainid)

All other methods are only available over HTTPS.
