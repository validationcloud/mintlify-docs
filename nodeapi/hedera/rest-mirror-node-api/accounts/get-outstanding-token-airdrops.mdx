---
title: "Get Outstanding Token Airdrops"
openapi: "/nodeapi/openapi/openapi-20jan-vc.json GET /api/v1/accounts/{idOrAliasOrEvmAddress}/airdrops/outstanding"
---

Returns outstanding token airdrops that have been sent by an account.

This method will use `20` [Compute Units](/nodeapi/about/billing).
