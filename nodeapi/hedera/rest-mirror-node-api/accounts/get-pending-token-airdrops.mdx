---
title: "Get Pending Token Airdrops"
openapi: "/nodeapi/openapi/openapi-20jan-vc.json GET /api/v1/accounts/{idOrAliasOrEvmAddress}/airdrops/pending"
---

Returns pending token airdrops that have been received by an account.

This method will use `20` [Compute Units](/nodeapi/about/billing).
