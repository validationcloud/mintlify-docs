---
title: "Get Contract Actions by ID or Hash"
openapi: "/nodeapi/openapi/hedera-openapi-5.json GET /api/v1/contracts/results/{transactionIdOrHash}/actions"
---

Get the contract actions from a contract on the network for a given transactionId or ethereum transaction hash.

This method will use `20` [Compute Units](/nodeapi/about/billing).
