---
title: "Get Opcodes Traces"
openapi: "/nodeapi/openapi/openapi-20jan-vc.json GET /api/v1/contracts/results/{transactionIdOrHash}/opcodes"
---

Get the opcode traces for a historical transaction on the network with the given transaction ID or hash.

This method will use `500` [Compute Units](/nodeapi/about/billing).
