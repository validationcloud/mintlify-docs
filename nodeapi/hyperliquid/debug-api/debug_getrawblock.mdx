---
title: "debug_getRawBlock"
---

Returns an RLP-encoded block.

This method will use `80` [Compute Units](/nodeapi/about/billing).

***

<Info>

This method is served by nanoreth, the HyperEVM archive client, and works for any block back to genesis. On blocks that carry a HyperCore deposit, block-level traces include the deposit as their first entry; see [Overview](/nodeapi/hyperliquid/overview).

</Info>

## **Parameters**

`blockNumber` - Quantity (hex) | Tag - <span style={{color: "red"}}>Required</span>  - The block number as a string in hexadecimal format or latest

## **Returns**

`result` - The RLP encoded block

```json
// Result
{
	"jsonrpc": "2.0",
	"result": "0xf94a4cf90266a06e9cc664b757b6bbb6d74b31a0060......",
	"id": 1
}
```

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.hyperliquid.validationcloud.io/v1/<YOUR_API_KEY_HERE>/evm \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0", "method":"debug_getRawBlock","params":["latest"],"id":1}'
    
```

</CodeGroup>
