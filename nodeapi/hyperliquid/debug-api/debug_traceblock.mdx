---
title: "debug_traceBlock"
---

Returns the traces of every transaction in an RLP-encoded block, replayed with the given tracer.

This method will use `80` [Compute Units](/nodeapi/about/billing).

***

<Info>

This method is served by nanoreth, the HyperEVM archive client, and works for any block back to genesis. On blocks that carry a HyperCore deposit, block-level traces include the deposit as their first entry; see [Overview](/nodeapi/hyperliquid/overview).

</Info>

## **Parameters**

`block` - String - <span style={{color: "red"}}>Required</span> - The RLP-encoded block as a hexadecimal string, for example the result of [debug\_getRawBlock](/nodeapi/hyperliquid/debug-api/debug_getrawblock).

`object` - Object - <span style={{color: "red"}}>Required</span> - The tracer object, same as [debug\_traceBlockByNumber](/nodeapi/hyperliquid/debug-api/debug_traceblockbynumber): `tracer` (`callTracer` or `prestateTracer`), optional `tracerConfig` and `timeout`.

## **Returns**

`array` - One entry per transaction in the block, each with a `txHash` and a `result` object in the shape the chosen tracer produces.
