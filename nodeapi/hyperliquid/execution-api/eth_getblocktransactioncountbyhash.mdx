---
title: "eth_getBlockTransactionCountByHash"
---

Returns the number of transactions in a block from a block matching the given block hash.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

<Info>

Over HTTPS, Hyperliquid Mainnet keeps roughly 165 days of blocks, receipts and logs; requests for older blocks return JSON-RPC error `-32603` with `invalid block height`. Over WebSocket the request is served by nanoreth, the HyperEVM archive client, and any block back to genesis is available.

</Info>

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth_getblocktransactioncountbyhash)

## **Parameters**

`DATA`, 32 Bytes - hash of a block

```bash
params: ["0xb903239f8543d04b5dc1ba6579132b143087c68db1b2168786408fcbce568238"]
```

## **Returns**

`QUANTITY` - integer of the number of transactions in this block.

```bash
// Result
{
  "id":1,
  "jsonrpc": "2.0",
  "result": "0xb" // 11
}
```

<CodeGroup>
