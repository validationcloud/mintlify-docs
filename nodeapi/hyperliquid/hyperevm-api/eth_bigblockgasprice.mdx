---
title: "eth_bigBlockGasPrice"
---

Returns the current gas price for HyperEVM big blocks. Big blocks are the larger, slower blocks used for contract deployment and other high-gas transactions; small blocks carry the rest.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

<Info>

Available over HTTPS only. This method is served by the Hyperliquid node, and WebSocket connections are served by nanoreth, which does not implement it.

</Info>

## Reference: [Here](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/hyperevm/json-rpc)

## **Parameters**

`None`

## **Returns**

`QUANTITY` - The big-block gas price in wei, as a hexadecimal string.

```json
// Result
{
    "jsonrpc": "2.0",
    "id": 1,
    "result": "0x5f5e100"
}
```

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.hyperliquid.validationcloud.io/v1/<YOUR_API_KEY_HERE>/evm \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_bigBlockGasPrice","params":[],"id":1}'
```

</CodeGroup>
