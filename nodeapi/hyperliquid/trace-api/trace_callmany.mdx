---
title: "trace_callMany"
---

Executes several message calls in sequence against the same state and returns the traces of each, without creating transactions on the block chain.

This method will use `80` [Compute Units](/nodeapi/about/billing).

***

<Info>

This method is served by nanoreth, the HyperEVM archive client, and works for any block back to genesis. On blocks that carry a HyperCore deposit, block-level traces include the deposit as their first entry; see [Overview](/nodeapi/hyperliquid/overview).

</Info>

## **Parameters**

1. `array` - A list of `[transaction, traceTypes]` pairs, executed in order, each later call seeing the state changes of the earlier ones:
   * `transaction` - Object - The call object with the same fields as [eth\_call](/nodeapi/hyperliquid/execution-api/eth_call) (`from`, `to`, `gas`, `gasPrice`, `value`, `data`).
   * `traceTypes` - Array - Any of `trace`, `vmTrace`, `stateDiff`.
2. `QUANTITY | TAG` - Integer block number, or the string `"latest"`, `"earliest"` or `"pending"`.

## **Returns**

`array` - One result per call, each with `output`, `trace`, `stateDiff` and `vmTrace` as requested.
