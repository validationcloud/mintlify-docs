---
title: "Construction API"
---

The construction API allows for offline signing of transactions and then posting them on ICP at a later point in time.

It is recommended to first go through [flow of operations](https://internetcomputer.org/docs/defi/rosetta/icp_rosetta/construction_api/operations-flow) of the construction API to gain an understanding of how it works, what endpoints to call with what parameters, and where the user has to take action upon receiving certain responses.
