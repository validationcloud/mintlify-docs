---
title: "eth_getTransactionCount"
---

Returns the number of transactions sent from an address.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

<Info>

Mantle Mainnet keeps historical state for the last 128 blocks, about 4 minutes at Mantle's 2-second block time. Requests for an older block return JSON-RPC error `-32000` with a message that contains `historical state <root> is not available`.

</Info>

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth_gettransactioncount)

## **Parameters**

1. `DATA`, 20 Bytes - address.
2. `QUANTITY|TAG` - integer block number, or the string `"latest"`, `"earliest"` or `"pending"`, see the [default block parameter](https://ethereum.org/en/developers/docs/apis/json-rpc/#default-block-parameter)

```javascript
params: [
  "0xe7cac669cc341bae5edda780538d2dcd5ba37bdc",
  "latest"
]
```

## Returns

`QUANTITY` - String hex value representing integer of the number of transactions sent from this address.

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x49f"
}
```

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.mantle.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_getTransactionCount","params":["0xe7cac669cc341bae5edda780538d2dcd5ba37bdc","latest"],"id":1}'
```

</CodeGroup>
