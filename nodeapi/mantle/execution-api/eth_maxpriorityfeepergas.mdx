---
title: "eth_maxPriorityFeePerGas"
---

Returns the priority fee per gas currently needed for a transaction to be included in a block.

This method will use `20` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

`None`

## Returns

`QUANTITY` - The suggested priority fee per gas, in wei, as a hexadecimal string.

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x186a0"
}
```
