---
title: "web3_clientVersion"
---

Returns the current client version.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#web3_clientversion)

## **Parameters**

`None`

## Returns

`string` - The current client version

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 67,
  "result": "Geth/v1.17.3-stable-e33cd26c/linux-amd64/go1.26.8"
}
```
