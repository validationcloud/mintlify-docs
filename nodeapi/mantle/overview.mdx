Mantle is an EVM-compatible scaling solution for Ethereum, built on the OP Stack as a ZK validity rollup. It produces a block every 2 seconds. Its native token is `MNT`.

Block explorer: [https://mantlescan.xyz](https://mantlescan.xyz)

Mantle's own developer documentation: [https://docs.mantle.xyz](https://docs.mantle.xyz)

## Network Support

| Network | Full History / Archive | HTTPS | WSS |
| --- | --- | --- | --- |
| Mantle Mainnet | <p>Blocks, receipts and logs ✅ to genesis<br /><br />State and Debug ❌ (last 128 blocks)</p> | ✅ | ✅ |

> Mantle Mainnet keeps historical state for the last 128 blocks, about 4 minutes at Mantle's 2-second block time. State methods (`eth_call`, `eth_createAccessList`, `eth_estimateGas`, `eth_getBalance`, `eth_getCode`, `eth_getProof`, `eth_getStorageAt`, `eth_getTransactionCount`, `eth_simulateV1`) and the [Debug API](/nodeapi/mantle/debug-api) work for blocks inside that window. Older blocks return JSON-RPC error `-32000` with a message that contains `historical state <root> is not available`.

> The Trace API (`trace_*`) is not available on Mantle. Use the [Debug API](/nodeapi/mantle/debug-api) for call traces.

> WebSocket clients **MUST** respond to server `ping` frames, otherwise the connection will be closed and re-established every minute.

## Getting Started

Send a request to check that your endpoint works. Replace `<YOUR_API_KEY_HERE>` with the key from your endpoint in the [Validation Cloud app](https://app.validationcloud.io/node).

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.mantle.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":0}'
```

</CodeGroup>

Connect over WebSocket:

<CodeGroup>

```bash title="mainnet"
wscat -c wss://mainnet.mantle.validationcloud.io/v1/wss/<YOUR_API_KEY_HERE>
```

</CodeGroup>
