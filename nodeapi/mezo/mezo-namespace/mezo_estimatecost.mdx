---
title: "mezo_estimateCost"
---

Estimates the cost necessary to execute a transaction.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

`object` - Object - <span style={{color: "red"}}>Required</span>  with the following fields:

* `from` - DATA, 20 Bytes - The address the transaction is send from.
* `from` - DATA, 20 Bytes - The address the transaction is send from.
* `from` - DATA, 20 Bytes - The address the transaction is send from.

## **Returns**

`object` containing:

* decimals - The decimals cost values are presented with.
* `usdCost` - Estimated USD cost presented using `decimals`. Divide by `10^decimals` to obtain the base USD value.
* `btcCost` - Estimated BTC cost presented using `decimals`. Divide by `10^decimals` to obtain the base BTC value.
