---
title: "debug_getRawHeader"
---

Returns an RLP-encoded header.

This method will use `80` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

`blockNumber` - Quantity (hex) | Tag - <span style={{color: "red"}}>Required</span>  - The block number as a string in hexadecimal format or latest

## **Returns**

`result` - The RLP encoded header

```json
// Result
{
	"jsonrpc": "2.0",
	"result": "0xf90267a087190141975a957b1ba...",
	"id": 1
}
```
