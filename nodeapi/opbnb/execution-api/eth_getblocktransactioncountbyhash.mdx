---
title: "eth_getBlockTransactionCountByHash"
---

Returns the number of transactions in a block from a block matching the given block hash.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth\_getblocktransactioncountbyhash)

## **Parameters**

`DATA`, 32 Bytes - hash of a block

```bash
params: ["0x6da3168a95ef9f6134d2bda97c1ef07b4c903cf9726d64433fd3d55e089bd0d2"]
```

## **Returns**

`QUANTITY` - integer of the number of transactions in this block.

```bash
// Result
{
  "id":1,
  "jsonrpc": "2.0",
  "result": "0xb" // 11
}
```
