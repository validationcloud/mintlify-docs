---
title: "net_listening"
---

Returns `true` if client is actively listening for network connections.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#net_listening)

## **Parameters**

`None`

## **Returns**

`Boolean` - `true` when listening, otherwise `false`.

```bash
// Result
{
  "id":67,
  "jsonrpc":"2.0",
  "result":true
}
```
