---
title: "eth_blockNumber"
---

Returns the number of most recent block.

This method will use `20` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth_blocknumber)

## **Parameters**

`None`

## Returns

`QUANTITY` - hexadecimal value of the current block number the client is on

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 0,
  "result": "0x2214c5c"
}
```
