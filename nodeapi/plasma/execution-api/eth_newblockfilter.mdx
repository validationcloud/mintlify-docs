---
title: "eth_newBlockFilter"
---

Creates a filter in the node, to notify when a new block arrives. To check if the state has changed, call [eth\_getFilterChanges](/nodeapi/plasma/execution-api/eth_getfilterchanges).

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth_newblockfilter)

## **Parameters**

`None`

## Returns

`QUANTITY` - A filter id.

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 73,
  "result": "0x372bf4b19e46dbb5720e14b0d33bb3bc"
}
```
