---
title: "eth_unsubscribe"
---

Cancels an existing subscription so that no further events are sent.

This method will use `20` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

`subscription ID` - string, the ID returned by an [eth\_subscribe](/nodeapi/plasma/execution-api/eth_subscribe) call

```json
params: [
  "0x2aac376f7b5415331eac766221de82e6"
]
```

## Returns

`true` if a subscription was successfully cancelled, or `false` if no subscription existed with the given ID.

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": true
}
```
