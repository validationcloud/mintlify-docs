---
title: "net_version"
---

Returns the current network id.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#net_version)

## **Parameters**

`None`

## **Returns**

`String` - The current network id.

Plasma Mainnet returns `9745`. The full list of network IDs is available at [chainlist.org](https://chainlist.org/).

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 0,
  "result": "9745"
}
```
