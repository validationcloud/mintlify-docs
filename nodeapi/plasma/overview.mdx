Plasma is a payments-focused Layer 1 blockchain built for stablecoin payments. It is EVM-compatible and produces a block about every second. Its native token is `XPL`.

Block explorer: [https://plasmascan.to](https://plasmascan.to)

Plasma's own developer documentation: [https://docs.plasma.org](https://docs.plasma.org)

## Network Support

| Network | Full History / Archive | HTTPS | WSS |
| --- | --- | --- | --- |
| Plasma Mainnet | ✅ | ✅ | ✅ |

> State methods such as `eth_call` and `eth_getBalance`, and the [Debug API](/nodeapi/plasma/debug-api/debug_traceblockbynumber), work for any block back to genesis. `eth_getProof` is the exception: it serves the latest block only.

> The Trace API (`trace_*`) is not available on Plasma. Use the [Debug API](/nodeapi/plasma/debug-api/debug_traceblockbynumber) for call traces.

> WebSocket clients **MUST** respond to server `ping` frames, otherwise the connection will be closed and re-established every minute.

## Getting Started

Send a request to check that your endpoint works. Replace `<YOUR_API_KEY_HERE>` with the key from your endpoint in the [Validation Cloud app](https://app.validationcloud.io/node).

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.plasma.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":0}'
```

</CodeGroup>

Connect over WebSocket:

<CodeGroup>

```bash title="mainnet"
wscat -c wss://mainnet.plasma.validationcloud.io/v1/wss/<YOUR_API_KEY_HERE>
```

</CodeGroup>
