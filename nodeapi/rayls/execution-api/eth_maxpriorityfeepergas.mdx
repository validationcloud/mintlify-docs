---
title: "eth_maxPriorityFeePerGas"
---

Get the priority fee needed to be included in a block.

This method will use `20` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

`None`

## Returns

`QUANTITY` - The current max priority fee per gas in wei.

```bash
// Result
{
  "id":1,
  "jsonrpc": "2.0",
  "result": "0x1" // 1
}
```
