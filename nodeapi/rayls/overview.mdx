Rayls is a three-layer blockchain architecture for institutional finance. Validation Cloud provides RPC access to the **Rayls Public Chain**, the EVM-compatible Layer 1 that anchors the network.

The Rayls Public Chain uses the Axyl execution client and supports standard Ethereum JSON-RPC methods, debug tracing, and trace APIs. It serves as the settlement and bridging layer for the broader Rayls ecosystem, which also includes a Privacy Ledger (Layer 2) and Commit Chains (Layer 3).

Block explorer: [https://explorer.rayls.com](https://explorer.rayls.com)

> WebSocket clients **MUST** respond to server `ping` frames, otherwise the connection will be closed and re-established every minute.

### Endpoint Capabilities

Rayls endpoints support both HTTP and WebSocket connectivity for production-grade applications.

#### HTTP

Best suited for:

* backend services and APIs
* blockchain data queries
* smart contract deployment and interaction
* development and testing workflows

#### WebSocket

Best suited for:

* real-time transaction monitoring
* event subscriptions
* live dashboards and analytics
* applications that require low-latency data delivery

### Getting Started

To start building on Rayls, connect your application to a Rayls endpoint and send standard Ethereum JSON-RPC requests.

Example request:

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.rayls.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":0}'
```

</CodeGroup>
