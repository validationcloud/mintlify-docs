---
title: "debug_traceBlockByHash"
---

Traces every transaction in the block specified by block hash and returns the tracer result for each one.

This method will use `80` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

`blockHash` - String - <span style={{color: "red"}}>Required</span> - The block hash.

`object` - Object - <span style={{color: "red"}}>Required</span> - The tracer object with the following fields:

* `tracer` - String - The type of tracer, options are: `callTracer`, `prestateTracer` or `flatCallTracer`.
  * `callTracer` - String - The callTracer keeps track of all call frames, including depth - calls, that are made during a transaction.
  * `prestateTracer` - String - The prestateTracer replays the transaction and tracks every part of state that occurred during the transaction.
  * `flatCallTracer` - String - The flatCallTracer is a specific type of tracer that provides a flattened view of all calls made during transaction execution. It offers a simplified output compared to the standard callTracer, in the same format as the `trace_` namespace used by other EVM clients.
* `tracerConfig` - Object (Optional) - The object to specify the configurations of the tracer.
  * `onlyTopCall` - Boolean - When set to true, this will only trace the primary (top-level) call and not any sub-calls. It eliminates the additional processing for each call frame.

## **Returns**

`result` - An array of transactions for that block, each containing:

* `txHash` - The transaction hash of the transaction.
* `result` - The tracer output for that transaction. With `flatCallTracer`, this is a list of calls, each containing:
  * `action` - The call: `callType`, `from`, `to`, `gas`, `input` and `value`.
  * `result` - The `gasUsed` and `output` of the call.
  * `subtraces` - The number of sub-calls made by this call.
  * `traceAddress` - The position of this call in the call tree.
  * `transactionHash`, `transactionPosition`, `blockHash` and `blockNumber` - Where the call happened.
  * `type` - The type of trace.
  * `beforeEVMTransfers` and `afterEVMTransfers` - Arbitrum-specific fee and refund transfers, on the top-level call.
