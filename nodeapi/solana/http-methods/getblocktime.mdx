---
title: "getBlockTime"
---

Returns the estimated production time of a block.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* `u64` integer _<span style={{color: "red"}}>Required</span>_. The block number, identified by Slot.

## Returns

* `result` The response can be either:
  * `i64`. The estimated production time, as Unix timestamp (seconds since the Unix epoch).
  * `null`. If timestamp is not available for the block.

```json
// Result
{
	"jsonrpc": "2.0",
	"result": 1739185378,
	"id": 1
}
```
