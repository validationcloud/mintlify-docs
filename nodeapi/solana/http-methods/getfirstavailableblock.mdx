---
title: "getFirstAvailableBlock"
---

Returns the slot of the lowest confirmed block that has not been purged from the ledger.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

None.

## Returns

`result` An integer slot of the lowest confirmed block as u64 (64-bit unsigned integer) integer.

```bash
// Result
{
	"jsonrpc": "2.0",
	"result": 319916978,
	"id": 1
}
```
