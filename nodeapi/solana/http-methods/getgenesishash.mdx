---
title: "getGenesisHash"
---

Returns the genesis hash.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

None.

## Returns

`result` The hash encoded as base-58 string.

```json
// Result
{
	"jsonrpc": "2.0",
	"result": "5eykt4UsFv8P8NJdTREpY1vzqKqZKvdpKuc147dw2N9d",
	"id": 1
}
```
