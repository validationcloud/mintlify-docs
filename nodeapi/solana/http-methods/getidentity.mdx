---
title: "getIdentity"
---

Returns the identity pubkey for the current node.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

None.

## Returns

`result` The result will be a JSON object with the following fields:

* `identity` The public key identity of the current node as base-58 encoded string.

```json
// Result
{
	"jsonrpc": "2.0",
	"result": {
		"identity": "HnnWuaRUp63oBLNbxpo5wjAuazp2ukobyUvGsvMKX85d"
	},
	"id": 1
}
```
