---
title: "getMaxRetransmitSlot"
---

Get the max slot seen from retransmit stage.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

None.

## Returns

`result` The slot number encoded as u64, 64-bit unsigned integer.

```json
// Result
{
	"jsonrpc": "2.0",
	"result": 320154013,
	"id": 1
}
```
