---
title: "getSlotLeaders"
---

Returns the slot leaders for a given slot range.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* `start_slot` string _<span style={{color: "red"}}>Required</span>._ The start slot encoded as u64, 64-bit unsigned integer.
* `limit` string. The limit encoded as u64, 64-bit unsigned integer.

## Returns

`result` The slot leaders for the specified slot range.

```json
// Result
{
	"jsonrpc": "2.0",
	"id": 1,
	"method": "getSlotLeaders",
	"params": [
		320163037,
		10
	]
}
```
