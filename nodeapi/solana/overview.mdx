Solana is a high-performance, layer 1 blockchain designed to support decentralized applications (dApps) requiring scalability. \
\
Solana's native token is `SOL`, it's used for transactions, executing smart contracts, and staking.

`Lamports` are the smallest unit of currency on the Solana blockchain, there are 1 billion lamports in 1 SOL.

## Network Support
| Network | HTTPS | WSS |
| --- | --- | --- |
| Mainnet <br />(also known as Mainnet-beta) | ✅ | ✅ |
| Devnet | ✅ | ✅ |

> WebSocket clients **MUST** respond to server `ping` frames, otherwise the connection will be closed and re-established every minute.

## Getting Started

Send a request to check that your endpoint works. Replace `<YOUR_API_KEY_HERE>` with the key from your endpoint in the [Validation Cloud app](https://app.validationcloud.io/node).

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.solana.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","id":1, "method":"getHealth"}'
```

```bash title="devnet"
curl https://devnet.solana.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","id":1, "method":"getHealth"}'
```

</CodeGroup>

Connect over WebSocket:

<CodeGroup>

```bash title="mainnet"
wscat -c wss://mainnet.solana.validationcloud.io/v1/<YOUR_API_KEY_HERE>
```

```bash title="devnet"
wscat -c wss://devnet.solana.validationcloud.io/v1/<YOUR_API_KEY_HERE>
```

</CodeGroup>
