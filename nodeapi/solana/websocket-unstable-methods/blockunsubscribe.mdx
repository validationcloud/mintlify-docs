---
title: "blockUnsubscribe"
---

Unsubscribe from block notifications.

This method will use `20` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

`subscriptionID` integer _<span style={{color: "red"}}>Required</span>_. The subscription id to cancel, ensuring it matches the previously generated subscription ID from the 'blockSubscribe' method.

## Returns

`result` boolean. The result will be a boolean value with unsubscribed success message.

```json
// Result
{ "jsonrpc": "2.0", "result": true, "id": 1 }
```
