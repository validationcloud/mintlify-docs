---
title: "eth_getBalance"
---

Returns the balance of the account of given address.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth_getbalance)

## **Parameters**

1. `DATA`, 20 Bytes - address to check for balance.
2. `QUANTITY|TAG` - integer block number, or the string `"latest"`, `"earliest"` or `"pending"`, see the [default block parameter](https://ethereum.org/en/developers/docs/apis/json-rpc/#default-block-parameter)

## Returns

`INTEGER` - Hex value representing integer of the current balance in WEI.

```bash
// Result
{
  "id":83,
  "jsonrpc": "2.0",
  "result": "0xd3c3b98d826609e80000" 
}
```
