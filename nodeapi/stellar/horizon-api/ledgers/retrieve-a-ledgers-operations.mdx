---
title: "Retrieve a Ledger's Operations"
openapi: "/nodeapi/openapi/horizon-openapi-vc.json GET /ledgers/{sequence}/operations"
---

This endpoint returns successful operations in a specific ledger.

This method will use `20` [Compute Units](/nodeapi/about/billing).
