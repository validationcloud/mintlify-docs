title: "Retrieve an Operation's Effects"
openapi: "/nodeapi/openapi/horizon-openapi-vc.json GET /operations/{id}/effects"

This endpoint returns the effects of a specific operation.

This method will use `20` [Compute Units](/nodeapi/about/billing).
