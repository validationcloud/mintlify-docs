---
title: "Order Books"
---

An order book is a collection of offers for a specific pair of assets.

The [latest ledger](https://developers.stellar.org/docs/data/apis/horizon/api-reference/structure/consistency) known to Horizon is included as an HTTP header in the response.

Learn more about [order books](https://developers.stellar.org/docs/learn/glossary#decentralized-exchange).
