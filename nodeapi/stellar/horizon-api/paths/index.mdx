---
title: "Paths"
---

Paths provide information about potential path payments. A path can be used to populate the necessary fields for a path payment operation.

The [latest ledger](https://developers.stellar.org/docs/data/horizon/api-reference/structure/consistency) known to Horizon is included as an HTTP header in the response.

Learn more about the two types of path payment: [`path payment strict send`](https://developers.stellar.org/docs/learn/fundamentals/transactions/list-of-operations#path-payment-strict-send) and [`path payment strict receive`](https://developers.stellar.org/docs/learn/fundamentals/transactions/list-of-operations#path-payment-strict-receive)
