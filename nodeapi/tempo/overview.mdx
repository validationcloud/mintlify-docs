Tempo is a purpose-built Layer 1 blockchain designed for payments. It is EVM-compatible and built to support high-throughput, low-latency transaction flows, with sub-second finality and near-zero transaction fees.

Tempo is optimized for stablecoin payments and supports payment-specific functionality such as batch transfers, memo fields, compliance tooling including blocklists and allowlists, and the ability to pay transaction fees in supported stablecoins.

Block explorer: [https://explore.tempo.xyz](https://explore.tempo.xyz)

## Getting Started

Send a request to check that your endpoint works. Replace `<YOUR_API_KEY_HERE>` with the key from your endpoint in the [Validation Cloud app](https://app.validationcloud.io/node).

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.tempo.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":0}'
```

```bash title="testnet"
curl https://testnet.tempo.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":0}'
```

</CodeGroup>

Connect over WebSocket:

<CodeGroup>

```bash title="mainnet"
wscat -c wss://mainnet.tempo.validationcloud.io/v1/wss/<YOUR_API_KEY_HERE>
```

```bash title="testnet"
wscat -c wss://testnet.tempo.validationcloud.io/v1/wss/<YOUR_API_KEY_HERE>
```

</CodeGroup>
