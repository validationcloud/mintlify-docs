---
title: "GetDelegatedResourceAccountIndexV2"
---

In Stake2.0, query the resource delegation index by an account. Two lists will return, one is the list of addresses the account has delegated its resources(toAddress), and the other is the list of addresses that have delegated resources to the account(fromAddress).

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* `value` - String - Account address, default hexString
* `visible` - Boolean - Optional. Specifies whether the address is in Base58 format (default: false).

## **Returns**

| Field        | Type      | Description                                                        |
| ------------ | --------- | ------------------------------------------------------------------ |
| account      | string    | Account address                                                    |
| fromAccounts | string\[] | The list of addresses that have delegated resources to the account |
| toAccounts   | string\[] | The list of addresses the account has delegated its resources to   |

```json
// Result
{
  "account": "TPswDDCAWhJAZGdHPidFg5nEf8TkNToDX1",
  "fromAccounts": [
    "TLUork4tLoGaH7jWAiuKH1w82C11111111",
    "TJFZXfUVjoyh7qc3ZsnfmsxGfnPvxQVFVf",
    "TLdZoaud5dYS9Jd9uDdvgHYcU8rR8WSsem"
  ]
}
```

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.tron.validationcloud.io/v1/<YOUR_API_KEY_HERE>/wallet/getdelegatedresourceaccountindexv2 \
    -X POST \
    -H "Content-Type: application/json" \
    -d '
{
  "value": "TPswDDCAWhJAZGdHPidFg5nEf8TkNToDX1",

'
```
