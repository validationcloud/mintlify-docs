---
title: "ListExchanges"
---

List all exchange pairs.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* visible - Boolean - Optional. Specifies whether the address is in Base58 format

## **Returns**

exchanges - List&lt;ExchangeCapsule> : All exchange pair list

For each parameter of the exchange pair, please refer to [GetExchangeById](/nodeapi/tron/tron-full-node-http-api/dex-exchange/getexchangebyid)
