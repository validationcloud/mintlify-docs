---
title: "GetTransactionFromPending"
---

Get transaction details from the pending pool.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* `value` - String - Transaction ID

## **Returns**

Transaction details, for explanation of each parameter, please refer to [gettransactionbyid](/nodeapi/tron/tron-full-node-http-api/query-the-network/gettransactioninfobyid).
