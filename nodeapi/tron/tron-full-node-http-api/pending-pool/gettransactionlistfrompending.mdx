---
title: "GetTransactionListFromPending"
---

Get transaction list information from pending pool.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

None.

## **Returns**

txId - String Array : Pending transaction IDs in the pool
