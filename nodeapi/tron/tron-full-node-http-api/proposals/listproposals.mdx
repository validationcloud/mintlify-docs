---
title: "ListProposals"
---

List all proposals.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

None.

## **Returns**

proposals - List&lt;ProposalCapsule> : Proposal list. For parameters of each proposal, pleae refer to [GetProposalById](/nodeapi/tron/tron-full-node-http-api/proposals/getproposalbyid).
