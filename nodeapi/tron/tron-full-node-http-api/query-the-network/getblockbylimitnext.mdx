---
title: "GetBlockByLimitNext"
---

Returns the list of Block Objects included in the 'Block Height' range specified.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* `startNum` - int32 - Starting block height, including this block.
* `endNum` - int32 - Ending block height, excluding that block.

## **Returns**

Block list, please refer to [/wallet/getblock](/nodeapi/tron/tron-full-node-http-api/query-the-network/getblock) for the content contained in block.
