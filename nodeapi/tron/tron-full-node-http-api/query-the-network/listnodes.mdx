---
title: "ListNodes"
---

Query the list of nodes connected to the API node.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

None.

## **Returns**

nodes - Node list, each node information includes the following fields:

| Field        | Type   | Description       |
| ------------ | ------ | ----------------- |
| address.host | string | node host address |
| address.port | int    | node port         |
