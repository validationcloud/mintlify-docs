---
title: "GetAssetIssueListByName"
---

Query the list of all the TRC10 tokens by a name.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* `value` - String - TRC 10 token name, default hexString.

## **Returns**

`assetIssue` - List&lt;assetIssueCapsule> : The list of all TRC10 tokens with the same name, please refer to [GetAssetIssueByAccount](/nodeapi/tron/tron-full-node-http-api/trc10-token/getassetissuebyaccount) for detailed fields of AssetIssueCapsule object.
