---
title: "UpdateAsset"
---

Update basic TRC10 token information.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* `owner_address` - String - The issuers address of the token, default hexString
* `description` - String - Token description, default hexString
* `url` - String - Token official website url, default hexString
* `new_limit` - int64 - Each token holder's free bandwidth
* `new_public_limit` - int64 - The total free bandwidth of the token
* `permission_id` - int32 - Optional, for multi-signature use
* `visible` - Boolean - Optional. Specifies whether the address is in Base58 format (default: false).

## **Returns**

Transaction object - JSON object: Unsigned transaction, please refer to the [Transaction](https://developers.tron.network/docs/tron-protocol-transaction) chapter for the fields contained in it. Since the transaction type is `UpdateAssetContract`, the fields contained in `raw_data.contract[0].parameter.value` in the transaction are as follows:

| Field              | Type   | Description                                                |
| ------------------ | ------ | ---------------------------------------------------------- |
| owner\_address     | string | Account address                                            |
| description        | string | Description                                                |
| url                | string | Token's website Url                                        |
| new\_limit         | int64  | The limit of Bandwidth point which each caller can consume |
| new\_public\_limit | int64  | The limit of Bandwidth point which all caller can consume  |
