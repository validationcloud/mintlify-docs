---
title: "eth_getProtocolVersion"
---

Returns the java-tron block version

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

None.

## Returns

`DATA` - the code from the given address.

```json
// Result
{
  "id":1,
  "jsonrpc": "2.0",
  "result": "0x"
}
```

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.tron.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_protocolVersion","params":[],"id":64}'
```

</CodeGroup>
