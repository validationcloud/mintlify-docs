---
title: "net_version"
---

Returns the current network id.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

`None`

## **Returns**

`String` - The current network id.

The full list of current network IDs is available at [chainlist.org](https://chainlist.org/). The Tron network is:

* `0x2b6653dc` (728126428): Tron Mainnet

```json
// Result
{
	"jsonrpc": "2.0",
	"id": 67,
	"result": "0x2b6653dc"
}
```

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.tron.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"net_version","params":[],"id":67}'
```
