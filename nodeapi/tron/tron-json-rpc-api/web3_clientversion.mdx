---
title: "web3_clientVersion"
---

Returns the current client version.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

`None`

## Returns

`string` - The current client version

```json
// Result
{
	"jsonrpc": "2.0",
	"id": 67,
	"result": "TRON/v4.8.0/Linux/Java1.8"
}
```

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.tron.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"web3_clientVersion","params":[],"id":67}'
```

</CodeGroup>
