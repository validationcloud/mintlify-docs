---
title: "GetCanWithdrawUnfreezeAmount"
---

Stake2.0 API: Query the withdrawable balance at the specified timestamp (confirmed state).

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* `owner_address` - String - Owner address, default hexString
* `timestamp` - Int64 - Query cutoff timestamp, in milliseconds
* `visible` - Boolean - Optional - Specifies whether the address is in Base58 format (default: false).

## **Returns**

`amount` - Int64 : withdrawable balance, unit is sun.
