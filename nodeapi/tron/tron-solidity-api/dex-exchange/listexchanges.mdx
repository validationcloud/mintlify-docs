---
title: "ListExchanges"
---

List all exchange pairs (Confirmed state).

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Query Parameters**

* `visible` - Boolean

## **Returns**

exchanges - List&lt;ExchangeCapsule> : All exchange pair list

For each parameter of the exchange pair, please refer to [GetExchangeById](https://developers.tron.network/reference/wallet-getexchangebyid).
