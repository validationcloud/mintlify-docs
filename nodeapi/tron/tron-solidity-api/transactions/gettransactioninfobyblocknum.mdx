---
title: "GetTransactionInfoByBlockNum"
---

Query the transaction fee, block height by block number.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* `num` - Int32 - <span style={{color: "red"}}>Required</span> - Block height

## **Returns**

This interface returns the TransactionInfo data of all transactions contained in the block of the specified height. For the content of each transaction Info, please refer to [walletsolidity/gettransactioninfobyid](/nodeapi/tron/tron-solidity-api/transactions/gettransactioninfobyid).
