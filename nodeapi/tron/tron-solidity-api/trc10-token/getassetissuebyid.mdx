---
title: "GetAssetIssueById"
---

Query a token by token id. Returns the token object, which contains the token name (Confirmed state).

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* `value` - String - The ID of the TRC10 token
* `visible` - Boolean - Optional - Specifies whether the address is in Base58 format (default: false)

## **Returns**

AssetIssueCapsule : Token found with the provided ID, please refer to [GetAssetIssueByName](/nodeapi/tron/tron-solidity-api/trc10-token/getassetissuebyname) for detailed fields.
