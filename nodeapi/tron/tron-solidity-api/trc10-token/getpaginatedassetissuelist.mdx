---
title: "GetPaginatedAssetIssueList"
---

Query the list of all the tokens by pagination (confirmed state). Returns a list of Tokens that succeed the Token located at offset.

This method will use `30` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

* `offset` - Int32 - The index of the start token
* `limit` - Int32 - The amount of tokens per page

## **Returns**

assetIssue - List&lt;AssetIssueCapsule> : The list of all TRC10 token, please refer to [GetAssetIssueByName](/nodeapi/tron/tron-solidity-api/trc10-token/getassetissuebyname) for detailed fields of AssetIssueCapsule object.
