---
title: "eth_blobBaseFee"
---

Returns the current base fee per blob gas, in wei.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://ethereum.github.io/execution-apis/api-documentation/)

## **Parameters**

`None`

## **Returns**

`QUANTITY` - hexadecimal value of the current blob base fee in wei.

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x1"
}
```

curl https://mainnet.unichain.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
