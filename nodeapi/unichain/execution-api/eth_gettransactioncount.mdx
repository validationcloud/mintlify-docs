---
title: "eth_getTransactionCount"
---

Returns the number of transactions sent from an address.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

<Info>

Unichain Mainnet keeps historical state for roughly the last 10,000 blocks, about 2.8 hours at Unichain's 1-second block time. Requests for an older block return JSON-RPC error `-32603` with a message that contains `state at block #<number> is pruned`.

</Info>

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth_gettransactioncount)

## **Parameters**

1. `DATA`, 20 Bytes - address.
2. `QUANTITY|TAG` - integer block number, or the string `"latest"`, `"earliest"` or `"pending"`, see the [default block parameter](https://ethereum.org/en/developers/docs/apis/json-rpc/#default-block-parameter)

```javascript
params: [
  "0xcabba9e7f4b3a885c5aa069f88469ac711dd4acc",
  "latest"
]
```

## Returns

`QUANTITY` - String hex value representing integer of the number of transactions sent from this address.

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0xbfeecb6"
}
```

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.unichain.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_getTransactionCount","params":["0xcabba9e7f4b3a885c5aa069f88469ac711dd4acc","latest"],"id":1}'
```

</CodeGroup>
