---
title: "eth_protocolVersion"
---

Returns the Ethereum wire protocol version the node supports.

This method will use `10` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth_protocolversion)

## **Parameters**

`None`

## **Returns**

`String` - hexadecimal value of the protocol version.

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x5"
}
```
