Unichain is a DeFi-focused Ethereum Layer 2 built by Uniswap Labs on the OP Stack. It is part of the Optimism Superchain and produces a block every second.

Developer docs: [https://docs.unichain.org](https://docs.unichain.org)

Mainnet block explorer: [https://uniscan.xyz](https://uniscan.xyz)

## Network Support
| Network          | Full History / Archive                                                                    | HTTPS | WSS |
| ---------------- | ----------------------------------------------------------------------------------------- | ----- | --- |
| Unichain Mainnet | <p>Blocks, receipts and logs ✅ to genesis<br /><br />State and Debug ❌ (last ~10,000 blocks)</p> | ✅     | ✅   |

> Unichain Mainnet keeps historical state for roughly the last 10,000 blocks, about 2.8 hours at one block per second. State methods (`eth_call`, `eth_createAccessList`, `eth_estimateGas`, `eth_getBalance`, `eth_getCode`, `eth_getProof`, `eth_getStorageAt`, `eth_getTransactionCount`, `eth_simulateV1`) and the [Debug API](/nodeapi/unichain/debug-api) work for blocks inside that window. Older blocks return JSON-RPC error `-32603` with a message that contains `state at block #<number> is pruned`.

> The Trace API (`trace_*`) is not available on Unichain. Use the [Debug API](/nodeapi/unichain/debug-api) for call traces.

> WebSocket clients **MUST** respond to server `ping` frames, otherwise the connection will be closed and re-established every minute.

### Endpoint Capabilities

Unichain endpoints support both HTTP and WebSocket connectivity for production-grade applications.

#### HTTP

Best suited for:

* backend services and APIs
* blockchain data queries
* smart contract deployment and interaction
* development and testing workflows

#### WebSocket

Best suited for:

* real-time transaction monitoring
* event subscriptions
* live dashboards and analytics
* applications that require low-latency data delivery

### Getting Started

To start building on Unichain, connect your application to a Unichain endpoint and send standard Ethereum JSON-RPC requests.

Example request:

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.unichain.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":0}'
```

</CodeGroup>
