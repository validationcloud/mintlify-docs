---
title: "debug_getRawTransaction"
---

Returns the EIP-2718 binary-encoded transaction.

This method will use `80` [Compute Units](/nodeapi/about/billing).

***

## **Parameters**

`tx_hash` - String <span style={{color: "red"}}>Required</span>  - The transaction hash.

## **Returns**

`result` - String or null. The EIP-2718 binary-encoded transaction as hex, or `null` if the transaction is not found.

```json wrap
}
```
