---
title: "eth_gasPrice"
---

Returns the current price per gas in wei.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth_gasprice)

## **Parameters**

`None`

## Returns

`String` - hex string value representing an integer of the current price per gas in WEI.

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 73,
  "result": "0x1406f40"
}
```

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.xlayer.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \

```
