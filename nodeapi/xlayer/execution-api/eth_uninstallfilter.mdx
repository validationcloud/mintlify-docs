---
title: "eth_uninstallFilter"
---

Uninstalls a filter with given id. Should always be called when watch is no longer needed. Additionally Filters timeout when they aren't requested with [eth\_getFilterChanges](/nodeapi/xlayer/execution-api/eth_getfilterchanges) for a period of time.

This method will use `20` [Compute Units](/nodeapi/about/billing).

***

## **Reference:** [**Here**](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth_uninstallfilter)

## **Parameters**

1. `QUANTITY` - The filter id.

```javascript
params: [
  "0x44bffb2eb18f06c417ea0d9fedcd764"
]
```

## Returns

`Boolean` - `true` if the filter was successfully uninstalled, otherwise `false`.

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 73,
  "result": true
}
```
