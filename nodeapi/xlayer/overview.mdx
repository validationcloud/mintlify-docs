X Layer is an Ethereum Layer 2 built by OKX on the OP Stack. It produces a block every second. Its native token is `OKB`.

Block explorer: [https://web3.okx.com/explorer/x-layer](https://web3.okx.com/explorer/x-layer)

X Layer's own developer documentation: [https://web3.okx.com/xlayer/docs](https://web3.okx.com/xlayer/docs)

## Network Support

| Network | Full History / Archive | HTTPS | WSS |
| --- | --- | --- | --- |
| X Layer Mainnet | ✅ since re-genesis (block 42,810,021) | ✅ | ✅ |

> X Layer moved from Polygon CDK to the OP Stack at block 42,810,021 on 27 October 2025. All account state carried over, so current balances and contracts are complete. State methods such as `eth_call` and `eth_getBalance`, the [Debug API](/nodeapi/xlayer/debug-api/debug_traceblockbynumber) and the [Trace API](/nodeapi/xlayer/trace-api/trace_block) work for any block from 42,810,021 onward. Blocks before the re-genesis are not served. Block requests for them return `null` and state requests return an error.

> `eth_getProof` serves the latest 128 blocks. Older blocks return JSON-RPC error `-32602`.

> WebSocket clients **MUST** respond to server `ping` frames, otherwise the connection will be closed and re-established every minute.

## Getting Started

Send a request to check that your endpoint works. Replace `<YOUR_API_KEY_HERE>` with the key from your endpoint in the [Validation Cloud app](https://app.validationcloud.io/node).

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.xlayer.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":0}'
```

</CodeGroup>

Connect over WebSocket:

<CodeGroup>

```bash title="mainnet"
wscat -c wss://mainnet.xlayer.validationcloud.io/v1/wss/<YOUR_API_KEY_HERE>
```

</CodeGroup>
