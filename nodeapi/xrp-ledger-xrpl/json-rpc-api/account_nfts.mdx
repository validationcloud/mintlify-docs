---
title: "account_nfts"
---

Returns a list of NFToken objects owned by the specified account.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://xrpl.org/docs/references/http-websocket-apis/public-api-methods/account-methods/account_nfts)

## **Parameters**

* `account` (string, required) The address of the account. The request returns a list of NFTs owned by this account.
* `ledger_hash` (string, optional) The unique hash of the ledger version to use.
* `ledger_index` (number or string, optional) The ledger index of the ledger to use, or a shortcut string such as `validated`, `closed` or `current`.
* `limit` (integer, optional) Limit the number of token pages to retrieve. Each page can contain up to 32 NFTs. Cannot be lower than 20 or more than 400. The default is 100.
* `marker` (marker, optional) Value from a previous paginated response. Resume retrieving data where that response left off.

## Returns

* `account` (string) The account that owns the list of NFTs.
* `account_nfts` (array) A list of NFTs owned by the account. Each NFT object has `Flags`, `Issuer`, `NFTokenID`, `NFTokenTaxon`, `URI`, `nft_serial` and, if set, `TransferFee`.
* `ledger_hash` (string) The identifying hash of the ledger used to generate this response.
* `ledger_index` (number) The ledger index of the ledger used to generate this response.
* `ledger_current_index` (number) The ledger index of the current in-progress ledger, if used.
* `validated` (boolean) If `true`, the information comes from a validated ledger version.
* `marker` (marker) Server-defined value indicating the response is paginated. Omitted when there are no additional pages.
