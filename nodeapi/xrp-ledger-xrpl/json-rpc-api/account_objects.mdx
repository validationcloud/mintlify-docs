---
title: "account_objects"
---

Returns all ledger entries owned by an account, in their raw ledger format. Use it for entry types that don't have a specialized method (such as `account_lines` or `account_offers`), or when you want the raw form.

This method will use `40` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://xrpl.org/docs/references/http-websocket-apis/public-api-methods/account-methods/account_objects)

## **Parameters**

* `account` (string, required) Get ledger entries associated with this account.
* `deletion_blockers_only` (boolean, optional) If `true`, only return ledger entries that would block this account from being deleted. The default is `false`.
* `ledger_hash` (string, optional) The unique hash of the ledger version to use.
* `ledger_index` (number or string, optional) The ledger index of the ledger to use, or a shortcut string such as `validated`, `closed` or `current`.
* `limit` (number, optional) The maximum number of ledger entries to include in the results. Must be within the inclusive range 10 to 400. The default is 200.
* `marker` (marker, optional) Value from a previous paginated response. Resume retrieving data where that response left off.
* `sponsored` (boolean, optional) If `true`, return only sponsored ledger entries; if `false`, only entries that are not sponsored. Requires the Sponsor amendment.
* `type` (string, optional) Filter results to a specific type of ledger entry, such as `check`, `escrow`, `nft_offer`, `offer`, `payment_channel`, `signer_list`, `state` (trust line) or `ticket`.

## Returns

* `account` (string) The account this request corresponds to.
* `account_objects` (array) Array of ledger entries in this account's owner directory, each in its raw ledger format.
* `ledger_hash` (string) The identifying hash of the ledger that was used to generate this response.
* `ledger_index` (number) The ledger index of the ledger that was used to generate this response.
* `ledger_current_index` (number) The ledger index of the open ledger, if used.
* `limit` (number) The limit that was used in this request, if any.
* `marker` (marker) Server-defined value indicating the response is paginated. Omitted when there are no additional pages.
* `validated` (boolean) If `true`, the information comes from a validated ledger version.
