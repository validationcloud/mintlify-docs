---
title: "fee"
---

Reports the current state of the open-ledger requirements for the transaction cost, as seen by the live rippled server.

This method will use `20` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://xrpl.org/docs/references/http-websocket-apis/public-api-methods/server-info-methods/fee)

## **Parameters**

`None`

## Returns

* `current_ledger_size` (string) Number of transactions provisionally included in the in-progress ledger.
* `current_queue_size` (string) Number of transactions currently queued for the next ledger.
* `drops` (object) Transaction cost information in drops of XRP: `base_fee`, `median_fee`, `minimum_fee` and `open_ledger_fee`.
* `expected_ledger_size` (string) The approximate number of transactions expected to be included in the current ledger.
* `ledger_current_index` (number) The ledger index of the current open ledger these stats describe.
* `levels` (object) Transaction cost information in fee levels: `median_level`, `minimum_level`, `open_ledger_level` and `reference_level`.
* `max_queue_size` (string) The maximum number of transactions that the transaction queue can currently hold.
