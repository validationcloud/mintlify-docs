These are the XRP Ledger public API methods that Validation Cloud serves, over both HTTPS and WebSocket.

Before you start, read the [Overview](/nodeapi/xrp-ledger-xrpl/overview). It covers the request format (JSON-RPC shaped, but not JSON-RPC 2.0), which methods are not served, how errors are returned and the Compute Units each method costs.
