---
title: "ping"
---

Returns an acknowledgement, so that clients can test the connection status and latency.

This method will use `20` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://xrpl.org/docs/references/http-websocket-apis/public-api-methods/utility-methods/ping)

## **Parameters**

`None`

## Returns

* A successful result contains no fields other than `status`. Measure the round-trip time from request to response as latency.

```json
// Result
{
  "result": {
    "status": "success"
  }
}
```
