---
title: "submit"
---

Submits a signed, serialized transaction to the network to be confirmed and included in future ledgers. Only submit-only mode (a signed `tx_blob`) is available through this endpoint; sign-and-submit mode, which requires the server to hold your secret, is not.

This method will use `80` [Compute Units](/nodeapi/about/billing).

***

## Reference: [Here](https://xrpl.org/docs/references/http-websocket-apis/public-api-methods/transaction-methods/submit)

## **Parameters**

* `tx_blob` (string, required) Hex representation of the signed transaction to submit. This can be a multi-signed transaction.
* `fail_hard` (boolean, optional) If `true`, and the transaction fails locally, do not retry or relay the transaction to other servers. The default is `false`.

## Returns

* `engine_result` (string) Text result code indicating the preliminary result of the transaction, for example `tesSUCCESS`.
* `engine_result_code` (integer) Numeric version of the result code.
* `engine_result_message` (string) Human-readable explanation of the transaction's preliminary result.
* `tx_blob` (string) The complete transaction in hex string format.
* `tx_json` (object) The complete transaction in JSON format.
* `accepted` (boolean) `true` if the transaction was applied, queued, broadcast, or kept for later.
* `account_sequence_available` (number) The next Sequence Number available for the sending account after all pending and queued transactions.
* `account_sequence_next` (number) The next Sequence Number for the sending account after all provisionally applied transactions.
* `applied` (boolean) `true` if this transaction was applied to the open ledger.
* `broadcast` (boolean) `true` if this transaction was broadcast to peer servers.
* `kept` (boolean) `true` if the transaction was kept to be retried later.
* `queued` (boolean) `true` if the transaction was put in the transaction queue.
* `open_ledger_cost` (string) The current open ledger cost before processing this transaction.
* `validated_ledger_index` (integer) The ledger index of the newest validated ledger at the time of submission.
