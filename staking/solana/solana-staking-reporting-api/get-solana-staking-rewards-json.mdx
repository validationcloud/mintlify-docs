---
title: "Get Solana Staking Rewards (JSON)"
---

### GET /v1/api/solana/solana/mainnet/rewards\_detailed

Retrieve detailed staking rewards for a registered delegator wallet within a date range. Rewards are returned per epoch, per stake account. For a daily summary in CSV format instead, see [Get Solana Staking Rewards (CSV)](/staking/solana/solana-staking-reporting-api/get-solana-staking-rewards-csv).

**Note:** it is expected that there are two `/solana` elements in the path.

#### Query parameters

| Parameter           | Type   | Required | Description                                                                             |
| ------------------- | ------ | -------- | --------------------------------------------------------------------------------------- |
| `delegator_address` | string | Yes      | The delegator wallet address. Must already be registered and indexed.                   |
| `start_date`        | string | Yes      | Start of the date range, in `YYYY-MM-DD` format.                                        |
| `end_date`          | string | No       | End of the date range, in `YYYY-MM-DD` format. Defaults to the current date if omitted. |

#### Request

```bash
curl --request GET \
  --url 'https://api.staking.validationcloud.io/v1/api/solana/solana/mainnet/rewards_detailed?delegator_address=BjoYYxH6C85YhLm3YboRsb9NDs38YrygZbguir8orboF&start_date=2025-06-12&end_date=2025-06-16' \
  --header 'Authorization: Bearer eyJh...<rest_of_bearer_token>'
```

#### Response

Rewards amounts are denominated in lamports (1 SOL = 1,000,000,000 lamports).

Each entry includes the `validator_address` the stake is delegated to, the `staking_account` (stake account) that earned the reward, and a `yield_type` identifying the kind of reward, for example `REWARD` for staking rewards and `JITO_TIP` for Jito MEV tips.
