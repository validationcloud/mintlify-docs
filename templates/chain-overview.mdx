## Getting Started

Send a request to check that your endpoint works. Replace `<YOUR_API_KEY_HERE>` with the key from your endpoint in the [Validation Cloud app](https://app.validationcloud.io/node).

{/* Copy the CodeGroup from a cheap method page of this chain (eth_blockNumber for EVM chains), one tab per network. */}

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.<chain>.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":0}'
```

```bash title="testnet"
curl https://testnet.<chain>.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":0}'
```

</CodeGroup>

{/* Only when Network Support marks WSS. Use the chain's real WebSocket URL (EVM chains: /v1/wss/<KEY>). */}

Connect over WebSocket:

<CodeGroup>

```bash title="mainnet"
wscat -c wss://mainnet.<chain>.validationcloud.io/v1/wss/<YOUR_API_KEY_HERE>
```

```bash title="testnet"
wscat -c wss://testnet.<chain>.validationcloud.io/v1/wss/<YOUR_API_KEY_HERE>
```

</CodeGroup>
