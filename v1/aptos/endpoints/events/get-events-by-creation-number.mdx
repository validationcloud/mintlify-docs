---
title: "Get Events by Creation Number"
openapi: "/v1/openapi/document-aptos-with-v1-fix.json GET /accounts/{address}/events/{creation_number}"
---

Event types are globally identifiable by an account address and monotonically increasing creation\_number. This API returns events corresponding to that event type.

This method will use `30` [Compute Units](/v1/about/billing).
