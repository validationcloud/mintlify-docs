---
title: "platform.getUTXOs"
---

Gets the UTXOs that reference a given set of addresses.

This method will use `20` [Compute Units](/v1/about/billing).

***

## Reference: [Here](https://docs.avax.network/reference/avalanchego/p-chain/api#platformgetutxos)

## **Parameters**

* `addresses` - \[]string - the addresses from which we want to retrieve the UTXOs.
* `limit` - int - (optional) At most limit UTXOs are returned. If limit is omitted or greater than 1024, it is set to 1024.
* `startIndex` - object - (optional) an object of an address and a utxo.
  * `address` - string
  * `utxo` - string
* `sourceChain` - string - (optional) the chain from which we want to fetch the UTXOs, (X or C).
* `encoding` - string - (optional) Specifies the format for the returned UTXOs. Can only be hex when a value is provided.

## Returns

* `numFetched` - string - the number of UTXOs fetched.
* `utxos` - \[]string - the UTXOs fetched.
  * `endIndex` - object - the last address and utxo that was fetched.
  * `address` - string
  * `utxo` - string
