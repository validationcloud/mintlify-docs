---
title: "platform.validates"
---

Get the IDs of the blockchains a Subnet validates.

This method will use `20` [Compute Units](/v1/about/billing).

***

## Reference: [Here](https://docs.avax.network/reference/avalanchego/p-chain/api#platformvalidates)

## **Parameters**

* `subnetID` - string - the blockchain’s ID.

## Returns

* `blockchainIDs` - \[]string - Each element is the ID of a blockchain the Subnet validates.

```json
// Result
{
  "jsonrpc": "2.0",
  "result": {
    "blockchainIDs": [
      "KDYHHKjM4yTJTT8H8qPs5KXzE6gQH5TZrmP1qVr1P6qECj3XN",
      "2TtHFqEAAJ6b33dromYMqfgavGPF3iCpdG3hwNMiart2aB5QHi"
    ]
  },
  "id": 1
}
```
