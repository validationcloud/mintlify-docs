---
title: "eth_unsubscribe"
---

Cancels an existing subscription so that no further events are sent.

This method will use `20` [Compute Units](/v1/about/billing).

***

## **Parameters**

`subscription name` - **string, same as previously returned from an** [eth\_subscribe](/v1/ethereum/execution-api/eth_subscribe) **call**

```json
params: [
  "0xd46e8dd67c5d32be8d46e8dd67c5d32be8058bb8eb970870f072445675058bb8eb970870f072445675",
]
```

## Returns

`true` if a subscription was successfully cancelled, or `false` if no subscription existed with the given ID.

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": true
}
```
