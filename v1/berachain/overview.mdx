Berachain is a high-performance EVM-Identical Layer 1 (L1) blockchain utilizing Proof-of-Liquidity (PoL) as a consensus mechanism.

Block explorer:

* Mainnet: [https://beratrail.io/](https://beratrail.io/)
* Testnet (bepolia): [https://bepolia.beratrail.io/](https://bepolia.beratrail.io/)

\
[Learn more by visiting Berachain's developer docs](https://docs.berachain.com/).
