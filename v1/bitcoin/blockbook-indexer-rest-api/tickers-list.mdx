---
title: "Tickers list"
---

Returns a list of available currency rate tickers (secondary currencies) for the specified date, along with an actual data timestamp.

This method will use `10` [Compute Units](/v1/about/billing).

***

## **Reference:** [**Here**](https://github.com/trezor/blockbook/blob/master/docs/api.md#tickers-list)

```bash
GET /api/v2/tickers-list/?timestamp=<timestamp>
```

## **Parameters**

**`timestamp`**- Unix timestamp, required.&#x20;

Example: `1704070861`
