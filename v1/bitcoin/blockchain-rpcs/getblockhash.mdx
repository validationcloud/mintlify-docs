---
title: "getblockhash"
---

Returns hash of block in best-block-chain at height provided.

This method will use `10` [Compute Units](/v1/about/billing).

***

## **Reference:** [**Here**](https://developer.bitcoin.org/reference/rpc/getblockhash.html)

## **Parameters**

**`height`** - numeric, required

The height index

## Returns

| Name | Type   | Description    |
| ---- | ------ | -------------- |
| hex  | string | The block hash |
