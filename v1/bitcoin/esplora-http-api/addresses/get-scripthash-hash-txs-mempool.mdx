---
title: "GET /scripthash/:hash/txs/mempool"
---

Get unconfirmed transaction history for the specified scripthash.

This method will use `10` [Compute Units](/v1/about/billing).

***

## **Parameters**

**`scripthash`** - required.&#x20;

## Returns

Get unconfirmed transaction history for the specified /scripthash.

Returns up to 50 transactions (no paging).

<CodeGroup>

```bash title="mainnet"
curl https://mainnet.bitcoin.validationcloud.io/v1/<YOUR_API_KEY>/scripthash/<scripthash>/txs/mempool \
 -X GET
```

```bash title="testnet"
curl https://testnet.bitcoin.validationcloud.io/v1/<YOUR_API_KEY>/scripthash/<scripthash>/txs/mempool \
 -X GET
```

</CodeGroup>
