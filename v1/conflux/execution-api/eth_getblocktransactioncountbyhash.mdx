---
title: "eth_getBlockTransactionCountByHash"
---

Returns the number of transactions in a block from a block matching the given block hash.

This method will use `20` [Compute Units](/v1/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth_getblocktransactioncountbyhash)

## **Parameters**

`DATA`, 32 Bytes - hash of a block

```bash
params: ["0xf6e5d0e39d2c922c6772abba968eec0dbf2d82d7d26ec2342fb11fb7c5118548"]
```

## **Returns**

`QUANTITY` - integer of the number of transactions in this block.

```bash
// Result
{
  "id":1,
  "jsonrpc": "2.0",
  "result": "0xb" // 11
}
```
