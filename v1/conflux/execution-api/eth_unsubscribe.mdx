---
title: "eth_unsubscribe"
---

Cancels an existing subscription so that no further events are sent.

This method will use `10` [Compute Units](/v1/about/billing).

***

## **Parameters**

`subscription name` - **string, same as previously returned from an** [eth\_subscribe](/v1/conflux/execution-api/eth_subscribe) **call**

```json
params: [
  "0x5302037dae412a3454143512a3c7617b",
]
```

## Returns

`true` if a subscription was successfully cancelled, or `false` if no subscription existed with the given ID.

```json
// Result
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": true
}
```
