---
title: "eth_getSystemTxsByBlockNumber"
---

Returns the system transactions in a block: transfers from HyperCore into HyperEVM, which the standard block and receipt methods do not list. Indexers that need deposit history call this method per block.

This method will use `40` [Compute Units](/v1/about/billing).

***

<Info>

Available over HTTPS only. This method is served by the Hyperliquid node, and WebSocket connections are served by nanoreth, which does not implement it.

</Info>

## Reference: [Here](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/hyperevm/json-rpc)

## **Parameters**

1. `QUANTITY|TAG` - Integer block number, or the string `"latest"`.

## **Returns**

`array` - The system transactions, in the shape of [eth\_getTransactionByHash](/v1/hyperliquid/execution-api/eth_gettransactionbyhash) results. `from` is the HyperCore system address, `gasPrice` is `0x0` and the signature fields are zero.
