---
title: "eth_chainId"
---

Returns the chain ID used for signing replay-protected transactions.

This method will use `10` [Compute Units](/v1/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth\_chainid)

## **Parameters**

`None`

## **Returns**

`chainId`, hexadecimal value as a string representing the integer of the current chain id.

```bash
// Result
{
  "id":67,
  "jsonrpc": "2.0",
  "result": "0x1"
}
```
