---
title: "eth_getBlockTransactionCountByNumber"
---

Returns the number of transactions in a block matching the given block number.

This method will use `40` [Compute Units](/v1/about/billing).

***

## Reference: [Here](https://ethereum.org/en/developers/docs/apis/json-rpc/#eth\_getblocktransactioncountbynumber)

## **Parameters**

`QUANTITY|TAG` - integer of a block number, or the string `"earliest"`, `"latest"` or `"pending"`, as in the [default block parameter](https://ethereum.org/en/developers/docs/apis/json-rpc/#default-block-parameter).

```bash
params: [
  "0xe8", // 232
]
```

## **Returns**

`QUANTITY` - integer of the number of transactions in this block.

```bash
// Result
{
  "id":1,
  "jsonrpc": "2.0",
  "result": "0xa" // 10
}
```
