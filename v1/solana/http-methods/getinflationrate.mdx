---
title: "getInflationRate"
---

Returns the specific inflation values for the current epoch.

This method will use `30` [Compute Units](/v1/about/billing).

***

## **Parameters**

None.

## Returns

`result` The result will be an object with the following fields:

* `epoch` The epoch during which these values remain valid.
* `foundation` The proportion of total inflation allocated to the foundation.
* `total` The total inflation.
* `validator` The portion of inflation designated for validators.

```bash
// Result
{
	"jsonrpc": "2.0",
	"result": {
		"epoch": 741,
		"foundation": 0.0,
		"total": 0.047237663454945594,
		"validator": 0.047237663454945594
	},
	"id": 1
}
```
