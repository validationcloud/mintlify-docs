---
title: "Retrieve a Transaction's Operations"
openapi: "/v1/openapi/horizon-openapi-vc.json GET /transactions/{transaction_hash}/operations"
---

This endpoint returns Successful operations for a specific transaction.

This method will use `20` [Compute Units](/v1/about/billing).
