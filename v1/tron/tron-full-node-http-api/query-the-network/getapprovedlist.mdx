---
title: "GetApprovedList"
---

Query the account address list which signed the transaction.

This method will use `30` [Compute Units](/v1/about/billing).

***

## **Parameters**

* `signature` - Array of strings - <span style={{color: "red"}}>Required</span> - The signature list of transaction
* `raw_data` - json- <span style={{color: "red"}}>Required</span> - The transaction raw data
* `visible` - Boolean - Optional. Whether the address is in base58check format.

## **Returns**

Json object: including the signed account address list `approved_list`, and the transaction information `transaction`.
