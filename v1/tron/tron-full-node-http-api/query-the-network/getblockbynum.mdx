---
title: "GetBlockByNum"
---

Returns the Block Object corresponding to the 'Block Height' specified (number of blocks preceding it).

This method will use `30` [Compute Units](/v1/about/billing).

***

## **Parameters**

* `num` - int32 - the block height.

## **Returns**

Block data, please refer to [/wallet/getblock](/v1/tron/tron-full-node-http-api/query-the-network/getblock) for the content contained in block.
