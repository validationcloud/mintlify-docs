---
title: "GetAssetIssueByName"
---

Query a token by name, returns token info.

This method will use `30` [Compute Units](/v1/about/billing).

***

## **Parameters**

* `value` - String - TRC 10 token name, default hexString.

## **Returns**

`AssetIssueCapsule` : Token found with the provided name, please refer to [GetAssetIssueByAccount](/v1/tron/tron-full-node-http-api/trc10-token/getassetissuebyaccount) for detailed fields.
