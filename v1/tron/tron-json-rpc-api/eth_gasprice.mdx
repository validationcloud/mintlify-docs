---
title: "eth_gasPrice"
---

Returns the current price per gas in wei.

This method will use `40` [Compute Units](/v1/about/billing).

***

## **Parameters**

`None`

## Returns

`String` - hex string value representing an integer of the current price per gas in WEI.

```bash
// Result
{
    "jsonrpc":"2.0",
    "id":73,
    "result":"0xffc1dc"//16761308 wei
} 
```

```bash title="mainnet"
curl https://mainnet.tron.validationcloud.io/v1/<YOUR_API_KEY_HERE> \
    -X POST \
```
