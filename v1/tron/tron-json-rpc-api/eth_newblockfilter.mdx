---
title: "eth_newBlockFilter"
---

Creates a filter in the node, to notify when a new block arrives. To check if the state has changed, call [eth\_getFilterChanges](/v1/tron/tron-json-rpc-api/eth_getfilterchanges).

This method will use `40` [Compute Units](/v1/about/billing).

***

## **Parameters**

`None`

## Returns

`QUANTITY` - A filter id.

```bash
// Result
{
  "id":1,
  "jsonrpc": "2.0",
  "result": "0x1" // 1
}
```
