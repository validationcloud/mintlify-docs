---
title: "GetAssetIssueList"
---

Query the list of all the TRC10 tokens (Confirmed state).

This method will use `30` [Compute Units](/v1/about/billing).

***

## **Parameters**

* `None`

## **Returns**

assetIssue - List&lt;AssetIssueCapsule> : The list of all TRC10 token, please refer to [GetAssetIssueByName](/v1/tron/tron-solidity-api/trc10-token/getassetissuebyname) for detailed fields of AssetIssueCapsule object.
