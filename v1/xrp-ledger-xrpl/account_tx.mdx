---
title: "account_tx"
---

Retrieves a list of validated transactions that involve a given account. Our XRPL endpoint serves this from Clio with the complete public history, so `ledger_index_min: -1` reaches back to ledger 32,570, the earliest ledger available anywhere on XRPL.

This method will use `40` [Compute Units](/v1/about/billing).

***

## Reference: [Here](https://xrpl.org/docs/references/http-websocket-apis/public-api-methods/account-methods/account_tx)

## **Parameters**

* `account` (string, required) The address of the account.
* `tx_type` (string, optional) Clio only. Return only transactions of a specific type, such as `Payment` or `OfferCreate`. Case-insensitive.
* `mpt_issuance_id` (string, optional) Clio only. Return only transactions that reference this MPTokenIssuanceID.
* `ledger_index_min` (integer, optional) The earliest ledger to include transactions from. `-1` means the earliest validated ledger available.
* `ledger_index_max` (integer, optional) The most recent ledger to include transactions from. `-1` means the most recent validated ledger available.
* `ledger_hash` (string, optional) Look for transactions from a single ledger only.
* `ledger_index` (string or integer, optional) Look for transactions from a single ledger only.
* `binary` (boolean, optional) If `true`, return transactions as hex strings instead of JSON. Defaults to `false`.
* `forward` (boolean, optional) If `true`, return values indexed with the oldest ledger first. Defaults to `false`.
* `limit` (integer, optional) Limit the number of transactions to retrieve. The server is not required to honor this value.
* `marker` (marker, optional) Value from a previous paginated response. This value is stable even if the server's range of available ledgers changes.
* `delegate` (object, optional) Filter by transaction delegation relationship, with `delegate_filter` (`actor` or `authorizer`) and optional `counter_party`.

## Returns

* `account` (string) The account this request corresponds to.
* `ledger_index_min` (integer) The ledger index of the earliest ledger actually searched.
* `ledger_index_max` (integer) The ledger index of the most recent ledger actually searched.
* `limit` (integer) The `limit` value used in the request.
* `marker` (marker) Server-defined value indicating the response is paginated.
* `transactions` (array) Array of transactions matching the request. Each has `ledger_index`, `tx` (or `tx_blob` in binary mode), `meta` (an object, or a hex string in binary mode) and `validated`.
* `validated` (boolean) If `true`, the information comes from a validated ledger version.
