---
title: "ledger_current"
---

Returns the ledger index of the current in-progress ledger. This call reaches the live rippled server (the open ledger), not Clio, so the value can change from one call to the next.

This method will use `20` [Compute Units](/v1/about/billing).

***

## Reference: [Here](https://xrpl.org/docs/references/http-websocket-apis/public-api-methods/ledger-methods/ledger_current)

## **Parameters**

`None`

## Returns

* `ledger_current_index` (unsigned integer) The ledger index of the current in-progress ledger version.

```bash
// Result
{
  "result": {
    "ledger_current_index": 107292935,
    "status": "success"
  },
  "status": "success",
  "type": "response",
  "forwarded": true
}
```
