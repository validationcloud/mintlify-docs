---
title: "nft_history"
---

Returns past transaction metadata for the NFT being queried, oldest or newest first, with pagination.

This method will use `40` [Compute Units](/v1/about/billing).

***

## Reference: [Here](https://xrpl.org/docs/references/http-websocket-apis/public-api-methods/clio-methods/nft_history)

## **Parameters**

* `nft_id` (string, required) A unique identifier for the non-fungible token (NFT).
* `ledger_index_min` (integer, optional) The earliest ledger to include. `-1` means the earliest validated ledger available.
* `ledger_index_max` (integer, optional) The most recent ledger to include. `-1` means the most recent validated ledger available.
* `ledger_hash` (string, optional) The unique hash of the ledger version to use.
* `ledger_index` (string or unsigned integer, optional) The ledger index of the ledger to use, or a shortcut string. Do not use `closed` or `current`; those forward the request to rippled, which does not support this method.
* `binary` (boolean, optional) If `true`, return transactions as hex strings instead of JSON. Defaults to `false`.
* `forward` (boolean, optional) If `true`, return values indexed with the oldest ledger first. Defaults to `false`.
* `limit` (unsigned integer, optional) Limit the number of transactions to retrieve. The server is not required to honor this value.
* `marker` (marker, optional) Value from a previous paginated response. Not stable if the server's range of available ledgers changes.

## Returns

* `nft_id` (string) The NFT this history is for.
* `ledger_index_min` (integer) The ledger index of the earliest ledger actually searched.
* `ledger_index_max` (integer) The ledger index of the most recent ledger actually searched.
* `limit` (integer) The `limit` value used in the request.
* `marker` (marker) Server-defined value indicating the response is paginated.
* `transactions` (array) Transactions that affected this NFT. Each has `ledger_index`, `tx` (or `tx_blob`), `meta` (or `meta_blob`) and `validated`.
* `validated` (boolean) If `true`, the information comes from a validated ledger version.
