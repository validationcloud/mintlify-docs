---
title: "nfts_by_issuer"
---

Returns a list of NFTokens that are issued by the specified account, optionally filtered by taxon.

This method will use `40` [Compute Units](/v1/about/billing).

***

## Reference: [Here](https://xrpl.org/docs/references/http-websocket-apis/public-api-methods/clio-methods/nfts_by_issuer)

## **Parameters**

* `issuer` (string, required) The address of the issuing account.
* `marker` (marker, optional) Value from a previous paginated response. Not stable if the server's range of available ledgers changes.
* `nft_taxon` (integer, optional) Filter NFTs issued by this issuer to those with this taxon.
* `ledger_hash` (string, optional) Look for NFTs issued up to the provided ledger. If not provided, the latest validated ledger is used.
* `ledger_index` (string or integer, optional) Look for NFTs issued up to the provided ledger. If not provided, the latest validated ledger is used.
* `limit` (integer, optional) Limit the number of NFTs to retrieve. The server is not required to honor this value.

## Returns

* `issuer` (string) The issuer's account address.
* `nfts` (array) A list of NFTs issued by the account. Each has `nft_id`, `ledger_index`, `owner`, `is_burned`, `uri`, `flags`, `transfer_fee`, `issuer`, `nft_taxon` and `nft_serial`. The order is not associated with the mint date.
* `marker` (marker) Server-defined value indicating the response is paginated. Omitted when there are no more pages.
* `limit` (integer) The `limit`, as specified in the request.
* `nft_taxon` (integer) The `nft_taxon` as specified in the request, if any.
* `ledger_index`, `validated` The ledger version used.
