---
title: "random"
---

Provides a random number to be used as a source of entropy for random number generation by clients.

This method will use `20` [Compute Units](/v1/about/billing).

***

## Reference: [Here](https://xrpl.org/docs/references/http-websocket-apis/public-api-methods/utility-methods/random)

## **Parameters**

`None`

## Returns

* `random` (string) Random 256-bit hex value.

```bash
// Result
{
  "result": {
    "random": "31961697CC7874B85BCA6F0F731F0C2449122BFCB9E74A8493F6C91343B6D81D",
    "status": "success"
  }
}
```
