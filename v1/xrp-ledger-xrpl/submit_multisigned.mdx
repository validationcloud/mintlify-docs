---
title: "submit_multisigned"
---

Applies a multi-signed transaction and sends it to the network to be included in future ledgers. You can also submit multi-signed transactions in binary form using the `submit` method.

This method will use `80` [Compute Units](/v1/about/billing).

***

## Reference: [Here](https://xrpl.org/docs/references/http-websocket-apis/public-api-methods/transaction-methods/submit_multisigned)

## **Parameters**

* `tx_json` (object, required) Transaction in JSON format with an array of `Signers`. To be successful, the weights of the signatures must be equal or higher than the quorum of the account's SignerList.
* `fail_hard` (boolean, optional) If `true`, and the transaction fails locally, do not retry or relay the transaction to other servers. The default is `false`.

## Returns

* `engine_result` (string) Code indicating the preliminary result of the transaction, for example `tesSUCCESS`.
* `engine_result_code` (integer) Numeric code indicating the preliminary result of the transaction.
* `engine_result_message` (string) Human-readable explanation of the preliminary transaction result.
* `tx_blob` (string) The complete transaction in hex string format.
* `tx_json` (object) The complete transaction in JSON format.
